# Sistema visual hidrométrico

La portada usa una superficie hidrométrica azul profunda como instrumento principal. Debajo aparecen sólo tres superficies secundarias: contexto territorial, alertas/acciones y fuentes/transparencia.

## Jerarquía

1. Alerta oficial vigente verificable, sólo cuando existe.
2. Situación hidrométrica: estación, nivel, vigencia, tendencia, cambio, timestamps, fuente y gráfico.
3. Contexto territorial compacto.
4. Alertas y acciones esenciales.
5. Fuentes y transparencia.

Los fallos del feed de alertas se reducen a un badge en header y un diálogo. El skip link queda oculto hasta foco. Los estados combinan texto, icono y color; reduced motion es obligatorio. No hay canvas decorativo, glassmorphism, fuentes externas ni dashboard genérico de tarjetas equivalentes.
