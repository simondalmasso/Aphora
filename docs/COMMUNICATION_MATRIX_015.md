# Matriz de comunicación pública — orden 015

| Situación | Texto principal | Acción | Prohibición |
| --- | --- | --- | --- |
| Alerta oficial vigente | `Alerta oficial activa` | Mostrar organismo, área, vigencia, instrucción y enlace | No reinterpretar ni ampliar la instrucción oficial |
| Feed de alertas vigente sin coincidencias | `Sin alertas oficiales detectadas` | Indicar hora de consulta y advertir que no equivale a ausencia de riesgo | No escribir `No hay alertas` |
| Feed de alertas demorado | `Verificación de alertas demorada` | Pedir verificación en el organismo | No inferir tranquilidad |
| Feed de alertas no disponible | `Fuentes de alertas no disponibles` | Enlazar canales oficiales humanos | No mostrar ausencia de alertas |
| Medición vigente | `Última medición` + estado de vigencia | Mostrar observado, recibido, válido hasta y antigüedad | No usar `en tiempo real` sin contrato demostrable |
| Medición demorada | `Actualización demorada` | Conservar como último dato y explicar límite | No usar verde ni inferir ausencia de riesgo |
| Medición vencida | `Última medición disponible` / `Desactualizado` | Verificar fuente oficial | No presentar como estado actual |
| Umbral superado | `Nivel por encima del umbral de referencia` | Mostrar diferencia y fecha | No decir `evacuación` sin orden oficial |
| Reporte ciudadano | `Reporte ciudadano` | Revisión privada por SOS Santa Fe | No mezclar con alerta oficial ni despacho |
| Cuota KV agotada | `El almacenamiento privado alcanzó temporalmente su límite gratuito` | Guardar borrador/reintentar | No sugerir upgrade, tarjeta ni pago |
| Sin conexión | `Sin conexión` | Mostrar fecha del último snapshot, contactos y borradores | No mostrar `Actualizado` ni ausencia de alertas |
| Servicio técnico | `Estado del servicio` | API operativa y última verificación técnica | No equiparar API operativa con datos vigentes |
