# SOS-SF Agent Instructions

Este repositorio usa construcción doble agéntica.

1. Leer y obedecer `RULES_SOS_SF.md`.
2. Para la construcción V1, leer íntegramente `START_HERE_ARQ.md`.
3. Leer después `ARQ_DEPLOY_OVERRIDE.md`; este archivo tiene precedencia sobre cualquier instrucción contradictoria de ejecución o despliegue.
4. Leer `OWNER_UI_MESSAGING_OVERRIDE_001.md` para conservar los botones Refresh/Mensajes y la arquitectura de mensajería pública/privada.
5. Leer y ejecutar íntegramente `OWNER_UI_SIMPLIFICATION_OVERRIDE_002.md`; tiene precedencia sobre cualquier decisión anterior de layout, densidad, exposición simultánea de módulos o jerarquía visual.

7. Si el agente actúa como ARQ 🛠️, ejecutar la orden vigente completa como un único tramo largo, continuo y autónomo.
8. No detenerse entre fases ni esperar a AUD durante la construcción interna; la aprobación visual requerida es un gate de despliegue, no una pausa de implementación.
9. No declarar la corrección lista para deploy sin SHA remoto, runs terminados, artifacts y capturas comparativas; no declarar despliegue hasta que el owner lo apruebe explícitamente.
10. No escribir en `simonkey888/Zungun`; sólo leerlo y reutilizar su semántica mediante el adapter desacoplado definido en el handoff.
11. Los secretos Cloudflare existen en GitHub Actions; no intentar leerlos ni pedirlos.
